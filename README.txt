BEACON TECHNOLOGY WEBSITE PACKAGE
=================================

Open index.html in a browser. Keep the assets folder beside it.

Folder structure:
  index.html
  assets/
    beacon-logo-primary.png
    beacon-logo-light.png
    beacon-icon.png
    beacon-brand-board.png
